## The image

One image, one story: the day's lead world story. Drones over the Kuwait City skyline at dusk, the Kuwait Towers, an air-defence radar in the foreground, and an explosion glowing on the horizon.

- Headline: DRONES STRIKE KUWAIT
- Two Italian technicians killed at an air-defence site.
- Italy and Kuwait blame Iran. Tehran denies any role.

Facts verified against reports from Reuters, BBC and CNN on 27 November 2026. The picture is an AI-generated illustration, labelled as such in the image, not a photograph of the attack.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.png`, a 1024 by 1024 image, 223,897 bytes. Node 22, standard library only, no network. Two runs produce byte-identical output.
